## Инцидент изоляции тестов

Новый тест аналитики первоначально импортировал приложение до установки временной `APP_DB`. Старые фикстуры полного прогона вследствие этого использовали `data/app.db` и очистили ряд таблиц. При диагностике обнаружены 5 пользователей (4 стандартных тестовых), 0 заявок, 0 организаций и 0 финансовых транзакций. Исходное содержимое до прогона не зафиксировано; утверждать, что пользовательские данные не потеряны, нельзя.

Текущее состояние сохранено в `output/product-fixes-2026-10-25/app-db-inspection-backup.db`. Это диагностическая копия после инцидента, не резервная копия исходных данных. Пользователь уведомлён; запрошено, были ли в базе нужные данные и где находится исходная резервная копия. Автоматическая подмена базы демонстрационными данными не выполнялась.

Исправлено назначение временной базы до импорта приложения и гарантированное восстановление тестовых ресурсов. Итоговый прогон дополнительно запущен с отдельной `APP_DB` на уровне процесса. Браузерные сценарии выполнялись в собственной базе и не использовали `data/app.db`.

## Ограничения

Аналитика объединяет заявки по дате создания в UTC+3 и показывает текущее состояние этой группы. Для срока завершения сохраняется существующая модель с `updated_at`; отдельная историческая отметка завершения в рамках этих шести исправлений не добавлялась. Целевой SLA показывается только при явной настройке `ANALYTICS_SLA_TARGET_PCT`.
