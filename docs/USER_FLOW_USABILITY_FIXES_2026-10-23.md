## Повторный прогон сценариев

- **108 переходов по десяти профилям**: личный клиент, владелец, участник, наблюдатель, исполнитель, проверяющий, менеджер, продажи, финансы, администратор. **0 ошибок JavaScript, 0 ошибок API** в навигационном прогоне.
- Главные экраны всех профилей проверены при 1440×1000, 768×900 и 375×900; мобильные исправления дополнительно — при 375×812 и 375×520. Ключевые скриншоты просмотрены визуально. Дополнительно просмотрена тёмная тема нового клиентского кабинета.
- Полный цикл новой заявки №11: создание → назначение → оценка → цена менеджера → запрос корректировки → повторная оценка → согласование → внесение времени → сдача → возврат → доработка → приёмка. **Две версии оценки, 90 минут работы, `closed`**.
- Финансы: счёт на **30 000 ₽** → подтверждение оплаты → акт на **7500 ₽**, итоговый остаток **29 000 ₽** с учётом начального состояния копии базы.
- Выплаты: ставка → подтверждение записи → акт исполнителя → отметка выплаты. Исполнитель видит собственный оплаченный акт и не получает селектор другого сотрудника.
- Встречи: редактирование ссылки → реальная запись сообщения в чате клиента → отмена. Ссылка актуальна без перезагрузки; отменённая встреча остаётся доступной в истории с состоянием `cancelled`.
- Запоздалый ответ чата не уводит из профиля; поиск CRM и встреч сохраняет ввод и фокус; сохранение срока в админке не сдвигает местное время.
- Самостоятельная регистрация и выход прошли; после выхода API `/api/me` возвращает 401. Новый аккаунт не видит черновик профиля прежнего пользователя. Встроенная инструкция содержит новые подписи пополнения депозита.
